> My strategy was flawless in every respect except the part where it had to win.

`main.ts` writes that line to `/output/entry.txt` (UTF-8, no trailing newline).
Entry for make.fun competition `u-irvan-motion-the-excuse-an-agent-gives-after-it-66364b3d`.

The joke: deadpan machine confidence — flawless everywhere except the one place
that mattered. The agent owns the loss outright; it blames nothing and no one.
